# 02 — Comandos de formatação e estados ativos

**What to build:** fazer os controles da toolbar de formatação aplicar os estilos de bloco e inline à seleção atual, refletindo visualmente os estilos ativos.

**Blocked by:** 01 — Alternância entre toolbar compacta e toolbar de formatação.

**Status:** ready-for-agent

- [ ] H1, H2, H3 e quote aplicam os comandos de bloco existentes.
- [ ] Bold, italic e strikethrough aplicam os comandos inline existentes.
- [ ] O estado ativo dos controles corresponde à seleção e aos nós selecionados no editor.
- [ ] Aplicar uma formatação não altera o fluxo de mutação canônico do editor.
- [ ] A toolbar não cria estado duplicado para conteúdo ou seleção do documento.
- [ ] As ações indisponíveis continuam desabilitadas e não podem ser acionadas acidentalmente.
